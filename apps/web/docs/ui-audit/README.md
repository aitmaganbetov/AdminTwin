# UI-аудит и переход на IBM Carbon

Дата: 27.11.2026. Стенд: ядро (`ADMINTWIN_DEV_AUTH`, симулятор, `infra/dev/fixtures.yaml`) + оркестратор (офлайн-модель) +
production-сборка UI (`next build && next start`). Данные «до» и «после» одинаковые: инцидент «HTTP 502 from upstream
app-api» с завершённым RCA, изменение `linux.logs.rotate_cleanup` (ждёт согласования), закрытое
`docker.container.restart`.

## Визуальный язык

- **Токены Carbon v11**: темы g10 (светлая) и g100 (тёмная) — значения взяты из `@carbon/themes` 11.86 и записаны
  в `src/app/globals.css` как `--cds-*`; отступы `--sp-01…10`, высоты `--control-h` (40 px), `--row-h` (40 px, таблицы
  размера md). Старые имена (`--surface`, `--accent`…) оставлены алиасами для SVG топологии.
- **Шрифты**: IBM Plex Sans 300/400/600 и IBM Plex Mono 400/600 из `@fontsource` (раздаются приложением, без CDN).
  Подмножества latin + cyrillic + cyrillic-ext; покрытие проверено fontTools: Ә Ғ Қ Ң Ө Ұ Ү Һ І, «», №, ₸ — все глифы есть.
- **Иконки**: `@carbon/icons-react` (обёртка `Icon` сохранила прежние имена). Логотип AdminTwin не менялся.
- **Компоненты** — в стиле Carbon, но на собственной разметке проекта. `@carbon/react` сознательно не подключён:
  он тянет Sass и собственные реализации всех компонентов, которые уже есть в проекте (`ui.tsx`), — получилось бы
  две параллельные библиотеки. Использованы только пакеты без рантайм-конфликтов (токены, иконки, шрифты).
- **Статусы** передаются цветом, формой иконки (Carbon status icons) и текстом.

## Что не проверено и почему

- **AI-провайдеры и бюджеты**, а также модули discovery и telemetry на экране «Здоровье платформы»: ядро не публикует `/api/v1/ai/*`
  (404). Видно только состояние «Модуль ещё не доступен»; таблицы провайдеров с данными не открывались.
  Ошибки 404 в консоли на этих экранах ожидаемы.
- **Чат-сессии** с живым потоком сообщений: оркестратор работал на офлайн-модели. Поток задачи RCA проверен,
  длинный диалог — нет.
- **Вход через OIDC**: нет IdP. Проверен только DEV-вход.
- **Ошибки сохранения**: в браузере проверены только ответы политики из `smoke.cjs` — 403 separation-of-duties
  для автора, 409 kill-switch-active для нового изменения, отзыв открытого согласования при kill switch.
  Ответ 5xx ядра и обрыв сети не воспроизводились.
- **Пагинация**: в интерфейсе её нет — API отдаёт списки целиком. Проверено 63 инцидента в одной таблице.
- **Экранные дикторы** (NVDA/VoiceOver) не запускались. Проверены порядок Tab, фокус, имена элементов (axe) и диалоги.
- **Safari/Firefox**: проверялся только Chromium.
